# rkplayer

飞牛 fnOS 上的电视端影视海报墙播放器。用遥控器方向键操作，走硬件解码看 4K HDR，支持多音轨切换、内嵌字幕与蓝光图形字幕。

现在提供两个平台的安装包：**RK3568 等 Rockchip 板卡（arm64）** 和 **Intel / AMD 核显的 x86_64 主机**。

## 环境要求

只在这两套环境上验证过，其它平台不保证能用：

| 项目     | arm64（RK3568）                                              | x86_64（Intel / AMD）                     |
| ------ | ---------------------------------------------------------- | -------------------------------------- |
| 硬件     | Rockchip **RK3568**（其它带 `/dev/mpp_service` 的 Rockchip 平台理论可用，未验证） | 带核显的 x86_64 主机，VA-API 可用（N100/N150 已验证）  |
| 系统     | 飞牛 fnOS **1.2.0701** 及以上                                    | 同左                                      |
| GPU 驱动 | 需先安装 **Mali GPU Driver** 应用（安装时会自动检查）                        | 无需额外驱动，Qt 运行时与 VA 插件随包                  |
| 硬解链路   | `/dev/mpp_service` + `gst-rockchip` 插件 + GStreamer ≥ 1.22（需 `playbin3`） | `/dev/dri/renderD*` + libva（随包带一份）      |
| 显示     | 安装时必须已接好显示器（HDMI / DSI / eDP 任一）                           | 同左                                      |
| 其他     | `python3`                                                  | 同左                                      |

装包前会自动检查上面这些项，缺哪项会直接告诉你缺什么，不会装上一个跑不起来的应用。

显示输出和音频设备在**安装时探测一次**并写进配置，之后的启动直接读结果。换了显示器或接口，需要重新探测。

## 安装

1. arm64：先在飞牛应用中心装好 **Mali GPU Driver**（x86_64 跳过这步）
2. 下载上面对应平台的 `.fpk`
3. 应用中心 → 手动安装 → 选这个文件
4. 安装向导里填影视服务器地址、账号密码

## 0.3.2 更新

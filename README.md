# rkplayer

飞牛 fnOS 上的电视端影视海报墙播放器，为 **RK3568** 这类 Rockchip 电视盒子 / 板卡做的。

用遥控器方向键操作的 10-foot 界面，走 RK3568 的硬件解码看 4K HDR，支持多音轨切换和内嵌字幕。

## 功能

**海报墙**
- 按「全部 / 精选 / 移动 / 本地」分类浏览，方向键移动焦点，卡片自动放大高亮
- 显示已看进度，一部剧看到一半下次直接续播

**详情页**
- 背景大图、简介、上映日期、片长、分级、制片国家、原始片名、音轨信息
- 「继续播放」直接从上次的位置接着放

**播放器**
- 硬件解码走 `mppvideodec`，4K HDR 片源在 RK3568 上流畅播放
- 内嵌字幕直读，不用外挂文件；字幕样式可调、可跨重启保存
- 多音轨切换（杜比环绕 / 杜比全景声等按片源自动列出）
- 倍速播放、进度条 ±10 秒快进快退
- 网盘片源可切画质，切换时等旧管线释放声卡再重建，不会黑屏或没声音

**遥控**
- 物理遥控器：方向键 / OK / 返回，交给系统按键映射，不需要额外配置
- 手机遥控：在飞牛桌面点「rkplayer 遥控器」，浏览器里就能操作，带进度、音量、播放状态回显

## 环境要求

只在这套环境上验证过，其它平台不保证能用：

| 项目 | 要求 |
|---|---|
| 硬件 | Rockchip **RK3568**（其它带 `/dev/mpp_service` 的 Rockchip 平台理论可用，未验证） |
| 系统 | 飞牛 fnOS **1.2.0701** 及以上 |
| GPU 驱动 | 需先安装 **Mali GPU Driver** 应用（安装时会自动检查） |
| 硬解链路 | `/dev/mpp_service` + `gst-rockchip` 插件 + GStreamer ≥ 1.22（需 `playbin3`） |
| 显示 | 安装时必须已接好显示器（HDMI / DSI / eDP 任一） |
| 其他 | `python3` |

装包前会自动检查上面这些项，缺哪项会直接告诉你缺什么，不会装上一个跑不起来的应用。

显示输出和音频设备在**安装时探测一次**并写进配置，之后的启动直接读结果。换了显示器或接口，需要重新探测。

## 安装

1. 在飞牛应用中心先装好 **Mali GPU Driver**
2. 下载本页 Release 里的 `rkplayer-0.2.3-arm.fpk`
3. 应用中心 → 手动安装 → 选这个文件
4. 安装向导里填影视服务器地址、账号密码
5. 装完在桌面点 `rkplayer` 图标启动

## 遥控

**物理遥控器**直接可用，方向键移动、OK 确认、返回键退出当前场景，播放器里按任意键唤出控件条。

**手机遥控**是把手机和电视接到同一个局域网，然后在飞牛桌面点「rkplayer 遥控器」图标——页面由飞牛自己托管，不需要电视端开任何端口。

按键做了长按连发，按住方向键 350ms 后开始连续移动；返回键有 200ms 去重，避免手机浏览器一次轻点发两套事件导致退两层。

## 授权

首次启动有 **7 天试用**，到期后需要授权码。

- 机器码和剩余天数在飞牛桌面「rkplayer 授权」页面直接能看到
- 把机器码发给作者换授权码，粘贴进去即可，电视端 5 秒内自动解锁，不用重启
- 授权码绑定机器，换设备需要重新申请

## 已知限制

- 只支持单屏输出。多屏环境下固定输出到安装时探测到的那一个口
- 授权页和遥控页依赖飞牛的应用内页面路径，飞牛大版本改动可能影响，届时会跟进修复
- 电视端没启动过的时候，授权页读不到机器码，会提示「电视端未运行」，先启动一次应用即可

- 画质选择与字幕字号跨重启保存
